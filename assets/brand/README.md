# 品牌资源

当前 MVP 的品牌图标与菜单栏标记位于本目录；应用图标和 SwiftPM 资源副本保持一致。功能界面使用 macOS 系统符号，不用品牌图替代操作含义。

- `Traylet.icns`：macOS 应用图标。
- `traylet-app-icon-1024.png`：关于页和应用资源使用的 1024px 图标。
- `traylet-logo.png`：透明底品牌标记。
- `traylet-menubar-template.png`：菜单栏单色标记参考图；实际菜单图形由源码绘制。

这些资产描述当前品牌，不代表 Dock、Finder、菜单栏、多显示器或各系统外观的实机视觉验收。
