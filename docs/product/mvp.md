# Traylet 首个 MVP：Beta 1

## 目标

提供一个本机运行的 macOS 菜单栏工具，让用户完成三件常见小任务：截取并标注图片、把文字或截图内容交给翻译、按需查看近期复制内容。首个 MVP 以清楚的用户控制和本机处理为基础，暂不依赖账号、云端或自动更新服务。

## 目标用户与场景

- 需要快速截取、标记并分享屏幕局部的人。
- 在阅读或工作时需要翻译短文本、截图文字的人。
- 需要在本机查找、复制近期文本或图片的人。

## MVP 功能

### 截图与编辑

- 从菜单栏发起区域截图或整屏截图。
- 对截图进行裁切和标注，支持形状、线条、箭头、文本、编号、高亮、模糊及不透明遮挡。
- 支持对象调整、缩放平移、撤销重做，并由用户明确选择复制或保存 PNG。

### 翻译

- 手动输入文本，或从截图/历史图片识别文本。
- 在提交翻译前查看并编辑识别结果。
- 默认使用 Apple 系统翻译；可选外部服务需由用户主动设置并发送。
- 允许取消请求，丢弃输入、语言或服务配置变化后返回的过期结果。

### 剪贴板历史

- 每次运行默认关闭；用户确认开启后才记录后续符合条件的文本和图片。
- 支持搜索、预览、复制、收藏、排序、删除和暂停。
- 支持配置记录类型、数量、期限、容量及排除应用。
- 普通历史默认只保存在内存中；本机持久保存需要单独选择并提示未加密和保留期限。

## 首个版本不承诺

- 滚动截图、窗口截图、自动拼接或自动采集前台内容。
- 云同步、账号、插件市场、自动更新或商业服务等级。
- 将模糊效果用于安全遮挡，或保证剪贴板能识别所有敏感信息。
- 与其他产品功能、性能或视觉上的完整对等。
- 未验证的系统权限、语言资源、在线服务质量、多屏、旧系统或物理输入行为。

## MVP 成功条件

1. 新用户可以从菜单栏进入三类核心任务并完成主要路径。
2. 屏幕内容、剪贴板记录和外部翻译发送都由用户动作触发；剪贴板默认关闭。
3. 失败、取消和迟到结果不会悄悄覆盖用户当前内容。
4. 首次 Beta 目标曾为 `0.1.0-beta.1` / build `1`，但该包因签名封装错误撤回；修正版目标为 `0.1.0-beta.2` / build `2`。公开分发前须完成 Developer ID 签名、公证和发行验收。

该范围描述首个 Beta 目标，不替代实际源码、运行证据或系统集成验收。
