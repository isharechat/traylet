# 产品地图

Traylet 首个 MVP 是原生 macOS 菜单栏工具，围绕截图编辑、手动翻译和用户主动开启的剪贴板历史。完整目标、包含/排除范围见[首个 MVP 说明](../product/mvp.md)。本文用于快速定位现有功能和开发资料。

## 菜单入口

- 截图：区域、屏幕
- 翻译：输入、截图
- 剪贴板
- 设置
- 退出

当前菜单不提供滚动/窗口截图、独立提取文字、自动粘贴、二维码、本次产物历史或云端功能。

## 功能到代码

| 功能 | 当前代码入口 | 用户可见结果 |
| --- | --- | --- |
| 截图与编辑 | `Sources/TrayletApp/Capture/`、`Features/Editing/` | 截图画布与编辑器；PNG复制或保存 |
| 输入/截图翻译 | `Features/Translation/` | 输入文本或识别图片、修改原文后提交 |
| 剪贴板历史 | `Features/Clipboard/` | 明确开启后的本机历史、搜索与管理 |
| 设置与快捷键 | `Settings/`、`Application/` | 通用、快捷键、翻译、剪贴板、关于 |
| 共享值 | `Sources/TrayletCore/` | 不可变图片与领域值 |

## 状态说明

- **实现**：源码中存在该行为。
- **合成验证**：fake、合成图或隐藏原生视图证明指定代码路径；不等同真实前台验收。
- **系统验收**：在正常应用启动、系统批准和真实设备环境下完成检查。
- **Beta 未放行**：测试或打包产物存在，但首个 Beta 的安装/发行验收仍未完成。

不把实现存在、测试通过、签名通过或 ZIP 生成混称为产品已验收。
