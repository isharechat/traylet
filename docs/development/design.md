# 原生界面与设计规范

## 平台原则

- 全部界面使用原生 **SwiftUI** 与 **AppKit** 窗口、菜单、文本输入、系统色盘与系统材质，不引入网页壳或跨平台控件库。
- 维持 Traylet 统一品牌图标与语义颜色系统，确保深色与浅色外观下的可读性与对比度。

## 材质与无障碍回退

- **macOS 26+ 双层桌面层级**：主工作窗口（设置、剪贴板、OCR）采用全高半透明 Liquid Glass 边栏（`224pt`–`300pt`）+ `52pt` 一体化无边标题栏（承载 `36pt` 胶囊控件）+ 干净不透明的主内容画布（`.textBackgroundColor`）；翻译窗保留 `40pt` 紧凑无边标题栏与三段式纯底文字区；浮窗工具栏与独立胶囊采用 `.glassEffect` / `NSGlassEffectView`，避免玻璃叠玻璃。
- **macOS 15–25**：边栏与浮动胶囊使用系统 `.regularMaterial` 与细高光描边作为平滑降级。
- **实底回退**：当用户在「设置 → 通用」关闭“启用玻璃效果”，或系统开启「减少透明度」「提高对比度」时，所有容器自动回退为不透明语义背景（`.underPageBackgroundColor` 边栏与 `.textBackgroundColor` 内容面）与清晰描边，布局尺寸保持不变。
- **减少动态**：尊重 `@Environment(\.accessibilityReduceMotion)`，关闭按钮按压缩放、色板放大等位移形变效果。

## 交互与布局约束

- **明确动作反馈**：涉及捕获、外发、删除、持久保存等副作用的操作使用明确动词与就近状态提示，写入失败或取消操作不清空用户当前内容。
- **键盘与输入法**：保留标准键盘导航与中文输入法组合态（IME）；文本编辑时不得因全局快捷键吞掉正在输入的按键。
- **响应式截图工具栏**：工具栏与附属选项条高度统一为 `40pt`，按画布宽度分三档响应：标准宽屏（`>= 480pt`）直出「矩形、箭头、文字、高斯模糊」四项核心标注工具，并将「椭圆、线条、铅笔、编号、高亮、遮挡」收纳进「更多标注工具」菜单；动作区保留「悬浮」独立按钮，将「翻译、OCR、保存 PNG」收纳进「更多操作」菜单，主「复制」按钮仅保留图标；紧凑宽度（`260..<480pt`）将标注工具全部收纳进「常用工具」菜单并保留「悬浮」与图标化「复制」；超窄宽度（`< 260pt`）仅保留动作菜单、关闭与图标化「复制」。
- **图层一致性**：截图编辑器预览与最终 PNG 导出共用同一合成顺序，不透明黑色遮挡始终位于最顶层。
