# 原生界面与设计规范

## 平台原则

- 全部界面使用原生 **SwiftUI** 与 **AppKit** 窗口、菜单、文本输入、系统色盘与系统材质，不引入网页壳或跨平台控件库。
- 维持 Traylet 统一品牌图标与语义颜色系统，确保深色与浅色外观下的可读性与对比度。

## 材质与无障碍回退

- **macOS 26+**：窗口与浮动胶囊默认使用 Liquid Glass（`.glassEffect` / `NSGlassEffectView`）。
- **macOS 15–25**：使用系统 `.regularMaterial` 与细高光描边作为平滑降级。
- **实底回退**：当用户在「设置 → 通用」关闭“启用玻璃效果”，或系统开启「减少透明度」「提高对比度」时，所有容器自动回退为不透明语义背景与清晰描边，布局尺寸保持不变。
- **减少动态**：尊重 `@Environment(\.accessibilityReduceMotion)`，关闭按钮按压缩放、色板放大等位移形变效果。

## 交互与布局约束

- **明确动作反馈**：涉及捕获、外发、删除、持久保存等副作用的操作使用明确动词与就近状态提示，写入失败或取消操作不清空用户当前内容。
- **键盘与输入法**：保留标准键盘导航与中文输入法组合态（IME）；文本编辑时不得因全局快捷键吞掉正在输入的按键。
- **响应式截图工具栏**：工具栏与附属选项条高度统一为 `40pt`，按画布宽度分四档响应：宽屏（`>= 740pt`）单行平铺全部 10 个标注工具与强调色胶囊「复制」主按钮；中等宽度（`560..<740pt`）将图形与遮挡收纳为分组菜单；紧凑及超窄宽度（`< 560pt`）逐级收纳次要入口至原生菜单。
- **图层一致性**：截图编辑器预览与最终 PNG 导出共用同一合成顺序，不透明黑色遮挡始终位于最顶层。
