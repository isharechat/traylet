# MVP 原生界面约束

## 平台

使用 SwiftUI 与 AppKit 原生窗口、菜单、文本输入、颜色面板和系统材质。维持 Traylet 当前品牌颜色与图标；不引入网页壳、跨平台控件库或仿制其他应用的品牌外观。

## 交互

- 菜单栏入口保持截图、翻译、剪贴板、设置和退出五类任务。
- 使用明确动词说明捕获、发送、开始记录、删除和持久保存等副作用。
- 失败信息紧邻可恢复动作；取消、关闭和失焦应有一致且可预期的结果。
- 保持键盘操作与输入法组合态；快捷键冲突不得吞掉正在输入的按键。
- 窄窗口中将次要工具放入原生菜单，主要输出操作仍可见。

## 视觉

- 内容区保持可读对比；玻璃材质遵循 macOS availability 与辅助功能的减少透明度偏好。
- 实底模式用语义窗口背景，不以透明底截图误判产品深色外观。
- 预览和导出共用同一编辑合成顺序；不透明遮挡覆盖其下图层。
- 原生离屏截图仅用于组件布局与像素回归；完成视觉验收仍需检查目标 app 的正常显示路径。

逐页行为和验收条件见[Beta 验收清单](acceptance.md)。
