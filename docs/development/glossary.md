# 词汇表

**截图**：用户明确发起后，从屏幕取得的一次图像。当前 MVP 提供区域和整屏截图。

**编辑会话**：针对一张截图或用户选择的图片进行裁切与标注的临时状态。复制或保存须由用户明确触发。

**截图翻译**：用户选择图片区域后进行本机 OCR；用户检查/修改识别文本后再明确提交翻译。

**翻译请求**：由文本版本、语言方向、服务配置和请求身份确定的一次翻译工作。输入变化、取消或关闭会使旧结果失效。

**外部服务发送**：将用户选定的正文发送到非 Apple 本机服务。必须明确服务目标、内容与发送动作。

**剪贴板记录**：用户本次运行确认开启后，记录确认之后的新复制内容；默认关闭且不补录。

**剪贴板历史**：本地会话中已记录并可搜索、复制或删除的条目集合。默认只在内存保存。

**本机保存**：用户主动选择后将历史/收藏写入本机归档；内容未加密，并有明确保留策略。

**合成证据**：以合成图文、fake 服务或隐藏宿主执行的断言与截图。它不能替代真实系统授权、前台交互或服务质量验收。

**Beta 放行**：满足[验收清单](acceptance.md)并对未完成项作明确处置的发行决定。构建成功或签名通过本身不代表放行。
