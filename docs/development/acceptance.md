# 首个 Beta 验收清单

本清单用于 `0.1.0-beta.3` / build `3`。产品目标见[首个 MVP](../product/mvp.md)；每项需记录环境、命令/动作、结果和证据路径。

## 本地功能回归

- [ ] SwiftPM 只编译当前 MVP 目标；滚动截图源/测试保持排除且不计为通过。
- [ ] 非并行应用测试完成，明确列出通过、跳过、排除和失败。
- [ ] Python 工具测试完成。
- [ ] 截图裁剪/对象编辑/撤销/复制/保存覆盖合成成功与失败路径。
- [ ] 输入翻译、截图 OCR 校正、提交、取消和迟到结果覆盖状态变化。
- [ ] 在真实前台应用中选中文本后触发输入翻译快捷键，原文框直接显示选中内容；辅助功能未授权时窗口仍可正常打开，并显示授权原因与系统设置入口；翻译设置可查看授权状态并请求权限。
- [ ] 设置中可检查并触发系统语言包下载；翻译窗口缺少资源时跳转设置并预填语言对，下载后重试。
- [ ] 剪贴板整段运行始终开启、启动后开始、不补录启动前内容、退出时停止；普通历史与收藏重启后从本机归档恢复。
- [ ] 剪贴板列表选中条目才展开详情，隐藏或删除选中项时收起；复制/删除/归档失败不丢用户内容。
- [ ] 中文/英文、深浅外观和窄窗基本可用。

## 系统验收

- [ ] 正常 LaunchServices 启动与直接执行分别记录权限状态。
- [ ] 用户主动授权后检查屏幕捕获和真实 Vision 路径。
- [ ] 真实系统翻译、缺少语言资源和取消/关闭路径。
- [ ] 真实剪贴板整段运行记录、系统采集、排除和退出停止行为。
- [ ] 前台焦点、物理键盘/IME、VoiceOver 和多显示器。
- [ ] macOS 15 最低版本路径；Intel 设备若宣称支持需单独验证。

## 包与放行

- [ ] `VERSION` 为 `0.1.0-beta.3`，`BUILD_NUMBER` 为 `3`。
- [ ] `.app` 的 `CFBundleShortVersionString` 为 `0.1.0`，`CFBundleVersion` 为 `3`，并含 `TrayletReleaseVersion=0.1.0-beta.3`。
- [ ] 包内二进制与同包合成证据一致；校验文件与 ZIP 哈希匹配。
- [ ] 当前测试结果、未解决问题、签名状态和安装状态分别报告。
- [ ] 发布前验证 Developer ID 签名、公证票据固定、Gatekeeper 评估和 SHA-256；任一项未通过不得创建公开 Release。

任何必需项失败或未执行时，报告阻塞或未验收，不以“构建成功”代替 Beta 放行。
