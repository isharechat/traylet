# 数据与隐私

## 本机处理

- 截图仅在用户发起截图时捕获；OCR 使用本机 Vision。
- 输入翻译快捷键只在用户显式触发时读取当前前台焦点元素的选中文本；不读取未选中的正文，不扫描窗口或整段文档。辅助功能未授权时返回无选区；安全输入框（`AXSecureTextField`）被拒绝。
- 辅助功能授权只通过 macOS 系统提示或设置页入口由用户本人完成；Traylet 不修改 TCC 记录、不绕过授权，也不会在未授权时改用模拟复制等方式读取选区。
- 编辑过程和默认翻译配置不自动上传内容。
- 外部翻译服务只在用户选择服务并明确提交文本后接收内容。通过“翻译”按钮首次向某引擎发送时，界面展示目标与正文并等待确认；用户直接点击引擎图标切换时视为明确提交，不再弹窗，直接发送当前可见原文。配置变化、取消或关闭使旧确认失效。
- 设置中的“获取模型”和“测试连接”由按钮直接触发：AI 服务只请求模型列表；DeepL 连接测试固定发送 `Hello.`。这些诊断请求不发送用户原文、截图或剪贴板内容。
- 设置中的“系统语言包”检查与下载只涉及所选原文/译文语言对。下载由 macOS 系统流程处理，Traylet 不直接读取或保存语言包文件，也不上传原文、截图或剪贴板内容。
- 服务凭据保存在 macOS 钥匙串（系统凭据库），不写入普通偏好文件；恢复默认设置时一并清除。

## 剪贴板历史

- 整段运行始终记录。启动时从新的 change-count 基线开始记录；不补录启动前已存在的内容。无逐次确认，也无运行时开启/关闭或暂停开关，仅在应用退出时停止。
- 类型开关、排除应用与容量限制不能隐式开启采集。
- 普通历史与收藏始终写入 `~/Library/Application Support/Traylet/v2/clipboard` 的未加密归档。用户可设置历史数量与保留期限，但没有关闭本机保存的开关。
- 删除单条、清空非收藏历史或删除所有收藏属于明确的用户动作；这些动作不修改当前系统剪贴板。
- 文本/富文本可能包含敏感内容；分类和系统标记不能保证识别所有秘密。

## 文件与旧数据

当前版本数据根目录为 `~/Library/Application Support/Traylet/v2/`。MVP 不导入、迁移或删除旧版数据，也不承诺安全擦除 SSD 快照或备份。正文尚未加载时，退出或调整无破坏设置不得用空状态覆盖归档。

## 权限

屏幕捕获和辅助功能使用 macOS 正常授权流程。语言资源下载由系统流程处理，权限或网络受阻时按失败处理并提供重试，不绕过系统确认。开发与交付脚本不得修改 TCC、Gatekeeper、系统信任或用户授权记录。

权限未获批准时，把对应系统流程记录为未验收；不得使用合成测试结果替代。
