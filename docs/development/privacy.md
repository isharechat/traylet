# 数据与隐私

## 本机优先处理

- **截图与编辑**：仅在用户主动发起截图时捕获屏幕，所有标注与合成均在本机完成，不上传任何图像。
- **输入翻译选区读取**：仅在用户显式触发快捷键时读取当前前台焦点元素的选中文本；不扫描窗口或未选中正文，拒绝读取安全输入框（`AXSecureTextField`）。
- **默认 OCR 与翻译**：默认使用本机 Apple Vision 与 Apple 系统翻译，全程离线运行。

## 外部请求边界

- **外部翻译服务**：仅在用户选择外部引擎（AI 翻译、DeepL、Google、MyMemory）并在翻译窗口显式发起翻译或切换引擎时发送当前可见原文。
- **AI OCR**：仅在用户显式切换至 AI OCR、点击识别/重试时，将当前图片以 Base64 形式发送至用户配置的 OpenAI 兼容接口。
- **连接诊断**：设置中的「获取模型」仅请求模型列表；DeepL「测试连接」固定发送 `Hello.`；均不携带用户原文、截图或剪贴板内容。
- **系统语言包**：由 macOS 系统流程下载与管理所选语言对资源。
- **软件更新**：仅在开启自动检查或手动点击「检查更新」时，向 GitHub Releases（`api.github.com`）发起只读请求获取版本信息与 `.sha256` 校验文件，不上传任何本机数据或标识信息。

## 凭据与本地存储

- **本机加密凭据库**：AI 翻译、DeepL 与 AI OCR 的 API Key 使用 AES-256-GCM 加密保存在 `~/Library/Application Support/Traylet/v2/credentials.enc`（密钥由随机密钥材料经 HKDF-SHA256 绑定本机硬件 UUID 与当前用户 UID 派生，文件权限限制为 `0600`），不写入明文配置文件；在设置中恢复默认设置时一并清除。
- **应用数据目录**：所有本机配置与归档统一存放于 `~/Library/Application Support/Traylet/v2/`（包括剪贴板归档 `clipboard` 与独立 OCR 配置 `ocr.json`）。
- **剪贴板采集边界**：应用启动时建立 `changeCount` 基线，仅记录运行期间新复制的受支持内容，不补录启动前内容，退出应用即停止；普通历史与收藏以未加密形式保存在本机归档中。

## 系统权限

屏幕录制、辅助功能与登录项均严格遵循 macOS 原生授权流程。任何脚本或测试均不得修改 TCC 记录、Gatekeeper 状态或系统信任设置。
