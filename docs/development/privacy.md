# 数据与隐私

## 本机处理

- 截图仅在用户发起截图时捕获；OCR 使用本机 Vision。
- 编辑过程和默认翻译配置不自动上传内容。
- 外部翻译服务只在用户选择服务并明确提交文本后接收内容。提交前界面应显示目标与正文；配置变化、取消或关闭使旧确认失效。
- 服务凭据当前只保存在内存中，不写入普通偏好文件。

## 剪贴板历史

- 每次运行默认关闭。用户明确确认后，从新的 change-count 基线开始记录；不补录开启前的内容。
- 类型开关、排除应用与容量限制不能隐式开启采集。
- 普通历史默认在内存中。本机保存需用户另行选择；数据未加密，用户可设置保留期限。
- 收藏的本机保存单独确认。删除、清空、关闭本机保存属于明确的用户动作。
- 文本/富文本可能包含敏感内容；分类和系统标记不能保证识别所有秘密。

## 文件与旧数据

当前版本数据根目录为 `~/Library/Application Support/Traylet/v2/`。MVP 不导入、迁移或删除旧版数据，也不承诺安全擦除 SSD 快照或备份。正文尚未加载时，退出或调整无破坏设置不得用空状态覆盖归档。

## 权限

屏幕捕获和辅助功能使用 macOS 正常授权流程。语言资源下载由系统流程处理。开发与交付脚本不得修改 TCC、Gatekeeper、系统信任或用户授权记录。

权限未获批准时，把对应系统流程记录为未验收；不得使用合成测试结果替代。
