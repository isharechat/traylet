# 翻译模块

**实现目录：** `Sources/TrayletApp/Features/Translation/`  
**测试目录：** `Tests/TrayletAppTests/Translation/`

负责输入翻译、截图/历史图片 OCR、翻译配置与请求生命周期。

## MVP 行为

- 默认系统翻译；OCR 使用本机 Vision。
- 输入翻译快捷键会先读取当前前台应用的选中文本；读取成功时翻译窗口直接以该文本预填原文并提交。辅助功能未授权、焦点不在可读文本框或应用不暴露选区时，窗口正常打开并保留原有输入。
- 选中文本读取需要 macOS 辅助功能授权；未授权时快捷键会触发一次系统授权提示，翻译窗口同时显示原因和“打开系统设置”入口。翻译设置的“辅助功能”分区显示当前授权状态，并提供请求权限或打开系统设置的按钮。
- 焦点元素查询优先询问前台应用自身的 `AXFocusedUIElement`，其次询问该应用焦点窗口上的同一属性，最后才回退到 system-wide 查询；每个元素都会核对 pid 与读取前后的焦点一致性。选区读取优先使用 `AXSelectedText`；部分应用只暴露 `AXSelectedTextRange` 时，通过 `AXStringForRange` 只读取所选范围，返回值同时兼容普通字符串与 `NSAttributedString`。拒绝安全输入框，选区最多保留 20,000 个字符。
- 用户可编辑 OCR 原文，再明确提交翻译。
- 外部服务由用户选择；通过“翻译”按钮首次向某引擎发送时展示目标与正文并等待确认；用户直接点击引擎图标切换时视为明确提交，不再弹窗，直接发送当前可见原文。配置变化或窗口关闭会撤销旧确认。
- 设置页的“获取模型”和“测试连接”直接执行，不弹确认框；按钮内显示进行中、成功或失败。点击“获取模型”后焦点自动移到模型输入框。模型下拉按钮默认常显，获取后可从面板中筛选选择；尚未获取时面板提示先获取模型。
- 设置页的“系统语言包”分区可选择原文与译文语言并检查系统翻译资源；状态区分未检查、检查中、已安装、可下载、不支持、下载中和失败。用户可提前触发下载，下载完成后自动重新检查。
- 语言包下载只通过系统 `TranslationSession.prepareTranslation()` 的一次性宿主执行；Traylet 不直接下载或保存语言包文件。切换语言、下载失败或页面消失会使旧请求失效。
- 翻译窗口遇到语言资源缺失时，可直接准备并翻译，也可“前往设置下载语言包”；跳转时预填当前语言对，自动检测原文时使用已检测语言。下载完成后返回翻译窗口重试。
- 自动检测先使用 NaturalLanguage，再对短文本做保守的书写系统回退；可用性检查和系统翻译会话使用解析出的明确源语言，避免把系统的“无法识别语言”误报成语言包检查失败。仍无法解析时不猜测源语言，提示用户选择明确原文语言。
- 输入、方向、配置或取消变化后，旧工作不能覆盖当前结果。
- 凭据保存在 macOS 钥匙串，不写普通配置文件；恢复默认设置时清除。

## 生命周期

系统 `TranslationSession` 限于当前 SwiftUI `translationTask` 宿主。不把 session 缓存在全局对象或复用到已关闭/配置已变的窗口。macOS 15 路径使用可用 API。

测试默认采用 fake 网络、资源和语音。语言包状态测试使用注入的系统资源检查与下载宿主；真实系统翻译、系统语言包下载与确认 UI、外部质量及服务条款需单独验收。
