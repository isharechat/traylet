# 剪贴板模块

**实现目录：** `Sources/TrayletApp/Features/Clipboard/`  
**测试目录：** `Tests/TrayletAppTests/Clipboard/`

负责用户主动开启后的记录策略、条目状态、搜索、复制、收藏及新版本机归档。

## 同意与采集

- 每次运行默认关闭；设置或窗口创建不启动 general 采集。
- 用户确认后建立当前基线，只记录之后的支持内容，不补录。
- 类型、排除、暂停、忽略下一次与录制同意是不同状态；设置变化不自动开启或清空历史。
- 应用自己的写入不能变成新的历史条目；混合类型内容按整次复制准入，不裁成部分内容。

## 历史与保存

- 默认历史在内存中；本机保存需确认，未加密并按期限清理。
- 收藏本机保存单独确认。正文未加载时不得用空集合覆盖归档。
- 原格式复制保持条目表示；纯文本复制是独立的用户动作。
- 图片编辑/OCR 不自动复制、不重建原历史条目；仅明确输出才写入剪贴板。

当前限额与存储实现以源码为准；真实 general 采集、确认弹窗和 VoiceOver 仍须系统验收。
