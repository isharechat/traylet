# 剪贴板模块

**实现目录：** `Sources/TrayletApp/Features/Clipboard/`  
**测试目录：** `Tests/TrayletAppTests/Clipboard/`

负责整段运行始终开启的记录策略、条目状态、搜索、复制、收藏及新版本机归档。

## 同意与采集

- 整段运行始终开启；应用启动即从新基线开始采集，无需逐次确认。
- 启动时建立当前基线，只记录之后的支持内容，不补录；无运行时开启/关闭或暂停开关，仅退出时停止。
- 类型、排除、忽略下一次是相互独立的设置；设置变化不自动清空历史。
- 应用自己的写入不能变成新的历史条目；混合类型内容按整次复制准入，不裁成部分内容。

## 历史与保存

- 普通历史与收藏始终写入本机归档（`archive.json` / `favorites.json`），应用启动时加载，重启后恢复；内容未加密并按数量与期限清理。
- 正文未加载时不得用空集合覆盖归档。删除单条、清空非收藏历史或删除所有收藏是明确的用户动作。
- 空闲轮询在未实际裁剪条目不替换历史数组，也不重复核对当前选区；只有条目被移除或搜索/收藏过滤变化时才重新核对，避免打开列表时空转重绘。
- 列表不再提供“展开详情”按钮；选中条目时展开详情列，清除、隐藏或删除选中项时收起。
- 原格式复制保持条目表示；纯文本复制是独立的用户动作。
- 图片编辑/OCR 不自动复制、不重建原历史条目；仅明确输出才写入剪贴板。

当前限额与存储实现以源码为准；真实 general 整段运行采集与 VoiceOver 仍须系统验收。
