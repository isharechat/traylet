# 设置模块

**实现目录：** `Sources/TrayletApp/Settings/`  
**测试目录：** `Tests/TrayletAppTests/Settings/`

设置页包含**通用、快捷键、翻译、剪贴板、权限、关于**六个分区。设置只持有对应模块的配置入口，不因展示或编辑偏好异常触发采集或外部请求。

- **快捷键**：录入与全局绑定提交分离；冲突或保存失败保留原绑定。
- **权限**：集中展示屏幕录制、辅助功能与登录时启动（`SMAppService`）状态，提供请求与系统设置跳转，并与启动后的失效引导弹窗联动。
- **关于**：展示版本信息与系统框架声明，以及内置开源自动更新开关（仅向 GitHub Releases API 发起只读检查，下载后强制校验 SHA-256 与签名）。
- 可破坏性动作须由明确用户动作确认；系统登录项由用户主动设置，不自行变更。

窗口真实焦点、登录项系统集成、VoiceOver 和多显示器需要按[发布验收清单](../acceptance.md)单独验收。
