# 截图编辑模块

**实现目录：** `Sources/TrayletApp/Features/Editing/`  
**测试目录：** `Tests/TrayletAppTests/Editing/`

接收屏幕截图或明确选择的图片，维护本次编辑状态，并将裁切和标注合成为输出 PNG。

## MVP 行为

- 选区可移动、缩放和按源图像素微调。
- 支持矩形、椭圆、线、箭头、铅笔、文字、编号、高亮、模糊及不透明遮挡。
- 支持已放对象编辑、视图适配/重置/平移、撤销/重做。
- 预览与复制/保存使用相同图层顺序。复制、保存和调用面板由明确用户动作触发。
- 写入失败、取消保存或关闭确认不得清空用户当前内容。

## 边界

滚动/窗口截图不属于编辑器输入能力。高斯模糊不作为安全涂黑；不透明遮挡负责覆盖最终输出像素。历史图片编辑使用普通编辑窗口，不读取屏幕、不替换正在进行的编辑。

系统选色盘、真实保存面板、物理 IME、前台焦点、多显示器与最低系统版本需按[验收清单](../acceptance.md)单独验证。
