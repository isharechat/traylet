# 截图与标注编辑

Traylet 提供区域截图、整屏截图以及基于原图的轻量标注编辑器，所有处理均在本机完成。

## 发起截图

- **区域截图**（默认 `⌃⌥1`）：进入全屏框选画布，拖动框选目标区域。
- **屏幕截图**（可在「设置 → 快捷键」绑定）：直接截取整块屏幕并进入编辑器。
- **剪贴板图片二次编辑**：在剪贴板历史中选中图片条目并点击「编辑图片」，将在独立普通编辑窗口中打开副本，不替换原历史记录，也不会读取屏幕。

> 注意：截图功能需要「屏幕录制」权限，可在「设置 → 权限」中授权。

## 选区调整与画布视图

在编辑器中可以随时微调选区或缩放平移画布：

- **移动与缩放选区**：未选中标注工具时，直接拖动选区移动，或拖动选区四周的八个控制点调整大小。
- **像素级微调**：
  - 方向键：按源图像素移动 `1 px`
  - `Shift` + 方向键：移动 `10 px`
  - `Command` + 方向键：调整选区宽高
- **视图操作**（仅影响预览缩放，不改变最终导出分辨率）：
  - `⌘2`：适配选区至当前视口
  - `⌘0`：重置视图缩放
  - 按住空格键并拖动：平移画布

## 标注工具

编辑器支持以下标注工具，并支持对已放置的标注对象进行二次选择、拖动移动、样式调整与按 `Delete` 删除：

- **基础图形**：矩形、椭圆、线条、箭头、铅笔
- **文本与编号**：文字（单击选中，双击或回车编辑，`⌘↩` 提交，`Esc` 取消）、编号（点击依次放置递增序号）
- **高亮**：固定 35% 透明度叠色，用于突出显示文字或局部内容
- **高斯模糊**：提供视觉柔化效果（仅作视觉遮挡，**不适用于**安全隐藏敏感信息）
- **不透明黑色遮挡**：纯黑不透明覆盖，始终显示在其他标注图层上方，适合遮挡敏感内容

同时支持完整的撤销（`⌘Z`）与重做（`⇧⌘Z`）。

## 输出与悬浮置顶

预览渲染与最终输出采用完全一致的图层合成顺序，所有输出均需由用户明确触发：

- **复制 PNG（`⌘C`）**：将合成后的图像写入系统剪贴板。
- **保存 PNG（`⌘S`）**：通过系统保存面板导出为 PNG 文件。
- **悬浮置顶（`⌘F`）**：将截图结果悬浮置顶到屏幕最上层（无标题栏窗口，初始出现在截图原位并保持原尺寸；拖动边缘可缩放窗口且图片自适应）。右键点击悬浮窗可选择复制、保存、删除或关闭。
- **退出编辑（`Esc`）**：关闭当前编辑会话。
