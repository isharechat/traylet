# 截图与标注编辑

Traylet 提供区域截图、整屏截图以及原生标注编辑器，所有图像处理均在本机完成。

## 发起截图

- **区域截图**（默认 `⌃⌥⇧A`）：进入全屏框选画布，拖动框选目标区域。
- **屏幕截图**（默认 `⌃⌥⇧S`）：直接截取整屏并进入编辑器。
- **剪贴板图片二次编辑**：在剪贴板历史中选中图片点击「编辑图片」，将在独立窗口中打开副本，不替换原历史条目。

> 截图功能需要「屏幕录制」权限，可在「设置 → 权限」中开启。

## 选区微调与画布视图

- **移动与缩放选区**：未激活标注工具时，拖动选区内部可移动位置，拖动四周八个控制点可调整大小。
- **像素级微调**：
  - 方向键：按源图像素移动 `1 px`
  - `Shift` + 方向键：移动 `10 px`
  - `Command` + 方向键：调整选区宽高
- **视图操作**（仅影响预览缩放，不改变最终导出分辨率）：
  - `⌘2`：适配选区至当前视口
  - `⌘0`：重置视图缩放
  - 按住空格键并拖动：平移画布

## 浮动工具栏与标注工具

工具栏与附属选项条采用统一的 `40pt` Liquid Glass 胶囊外观，拖动左侧 `2×3` 圆点抓手可自由移动位置，双击抓手复位。工具栏会根据窗口宽度自动切换布局：宽屏下全部 10 个工具单行直出，窄屏下自动收纳为原生分组菜单。

支持对已放置的标注对象进行二次选中、拖动移动、样式调整与按 `Delete` 删除，并支持完整的撤销（`⌘Z`）与重做（`⇧⌘Z`）：

- **图形与绘制**：矩形、椭圆、线条、箭头、铅笔（支持线宽预设、数值微调、7 色色板与系统色盘；矩形/椭圆支持填充切换）。
- **文字**：单击选中，双击或按回车进入编辑，`⌘↩` 提交，`Esc` 取消；支持字号预设与数值微调。
- **编号**：点击依次放置递增序号圆标，支持调整字号与颜色。
- **高亮**：固定 35% 透明度叠色，用于突出显示文字或局部内容。
- **高斯模糊**：画笔涂抹柔化（支持小/中/大预设与滑块调节直径；仅作视觉效果，**不适用于**安全隐藏敏感信息）。
- **遮挡**：不透明纯黑矩形覆盖，始终渲染在其他标注图层上方，适合遮蔽敏感内容。

## 输出与悬浮置顶

预览渲染与最终导出采用完全一致的图层合成顺序，所有输出均由用户明确触发：

- **复制（`⌘C`）**：工具栏右侧强调色胶囊主按钮，将合成图像写入系统剪贴板并关闭编辑器。
- **保存（`⌘S`）**：打开系统保存面板导出 PNG 文件。
- **翻译**：对当前选区图像执行 OCR 并进入翻译流程。
- **OCR**：将当前裁切与标注结果送入独立 OCR 窗口，同时**保留编辑器开启**以便继续标注。
- **悬浮置顶（`⌘F`）**：将截图悬浮置顶到屏幕最上层（无标题栏窗口，初始出现在原截图位置并保持原尺寸；拖动边缘可缩放且图像自适应）。右键点击悬浮窗可复制、保存、删除或关闭。
- **关闭（`Esc`）**：退出当前编辑会话。
