# 剪贴板历史

Traylet 提供始终本机保存的剪贴板历史管理，记录应用运行期间新复制的文本、链接与图片。

## 记录机制与生命周期

- **整段运行记录**：应用启动时记录当前系统剪贴板的 `changeCount` 基线，仅采集启动之后新复制的支持内容，**不会补录**启动前系统剪贴板中的已有内容。
- **随应用启停**：应用运行期间持续记录，没有运行时开启或暂停开关；退出 Traylet 后即停止记录。
- **忽略下一次复制**：在剪贴板窗口的工具栏菜单中可临时标记「忽略下一次复制」，跳过紧接着的一次复制操作而不中断后续记录。
- **自写不回流**：通过 Traylet 复制历史条目或输出截图时，不会重复生成一条新的历史记录。

## 剪贴板窗口（默认 `⌃⌥V`）

- **筛选与搜索**：支持按「全部 / 文本 / 链接 / 图片」分类过滤、关键词搜索，以及一键「仅看收藏」。
- **列表与详情**：打开窗口时默认不自动选中条目；鼠标点击或键盘上下选择条目后，右侧以过渡动画展开详情预览列；取消选中、搜索隐藏或删除选中项时自动收起。
- **条目操作**：
  - **原格式复制** / **纯文本复制**
  - **收藏 / 取消收藏**（收藏条目可优先保留并单独筛选）
  - **图片专属操作**：对历史图片条目发起「编辑副本」或「OCR 翻译」
  - **删除**：删除单条、清空非收藏历史或删除所有收藏（均不影响当前系统剪贴板内容）

## 本机存储与设置

所有普通历史与收藏均保存在本机归档目录：

```text
~/Library/Application Support/Traylet/v2/clipboard
```

- 数据采用未加密归档存储，重启应用后自动恢复。
- 可在「设置 → 剪贴板」中配置：
  - 允许记录的类型（文本、图片等）
  - 最大记录条数、保留期限与存储容量上限
  - **排除应用**：填入逗号分隔的 Bundle ID，忽略来自特定应用（如密码管理器）的复制内容。

> 安全提示：剪贴板内容未加密保存，系统分类与排除规则无法保证识别所有敏感信息，建议为密码管理器等敏感应用配置排除 Bundle ID。
