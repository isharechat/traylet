# 剪贴板历史

Traylet 提供始终本机保存的剪贴板历史管理，自动记录应用运行期间新复制的文本、链接与图片。

## 记录机制与生命周期

- **运行期自动记录**：应用启动时记录当前系统剪贴板的 `changeCount` 基线，仅采集启动之后新复制的支持内容，**不会补录**启动前剪贴板中的已有内容。
- **随应用启停**：应用运行期间持续记录，没有运行时开启或暂停开关；退出 Traylet 后即停止记录。
- **忽略下一次复制**：可在剪贴板窗口的工具栏菜单中临时标记「忽略下一次复制」，跳过紧接着的一次复制操作而不中断后续记录。
- **自写不回流**：通过 Traylet 复制历史条目、输出截图或使用输入翻译兜底策略时，不会重复生成新的历史记录。

## 剪贴板窗口（默认 `⌃⌥⇧V`）

- **筛选与搜索**：支持按「全部 / 文本 / 图片 / 链接」分类胶囊切换查看（关闭剪贴板后再次打开默认回到「全部」）、关键词搜索以及「仅收藏」叠加筛选。
- **图片略缩图与预览**：在「图片」分类下以双列略缩图网格展示，「全部」列表中图片条目亦展示清晰横向略缩图；单击条目在伴随详情弹窗中预览，点击详情中的图片、卡片预览按钮或按 `Space` / `⌘Y` 可打开按图片原始屏幕尺寸自适应居中的独立预览窗，支持放大/缩小后直接点击图片拖动平移查看与双击切换缩放。
- **列表与详情（伴随弹窗）**：主历史列表为紧凑单栏窗口（默认 `380×520`，红黄绿按钮与 `44pt` 顶栏工具条对齐）；打开窗口时默认不自动选中条目，点击或使用方向键选中条目后，在列表旁自动弹出与主窗等高同步缩放的伴随详情弹窗展示完整正文与动作栏，取消选中或删除后自动收起。
- **条目操作**：
  - **原格式复制** / **纯文本复制**
  - **收藏 / 取消收藏**（收藏条目可优先保留并单独筛选）
  - **文本 / 链接 / 图片详情联动**：
    - 文本条目可直接在详情底部或右键菜单点击「翻译」，带入翻译窗口并自动发起翻译
    - 链接条目保持正文可选中复制，并通过底部浏览器按钮或右键菜单在默认浏览器中打开
    - 图片条目支持直接发起「OCR 识别」、带入「截图翻译」或「编辑副本」（大图预览窗亦同步提供入口）
  - **删除**：删除单条、清空非收藏历史或删除所有收藏（均不修改当前系统剪贴板）

## 本机归档与设置

所有普通历史与收藏均保存在本机归档目录：

```text
~/Library/Application Support/Traylet/v2/clipboard
```

- 采用未加密本地归档存储，重启应用后自动恢复。
- 可在「设置 → 剪贴板」中配置允许记录的类型、最大记录条数、保留期限、容量上限以及**排除应用**（填写逗号分隔的 Bundle ID）。

> 安全提示：剪贴板内容未加密保存，建议将密码管理器等敏感应用的 Bundle ID 加入排除列表。
