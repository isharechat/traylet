# 文字与截图翻译

Traylet 支持手动输入翻译、划词预填翻译与截图 OCR 翻译，默认采用 Apple 本机系统翻译，同时可选接入外部翻译服务。

## 翻译入口

### 输入翻译（默认 `⌃⌥T`）

触发快捷键后，Traylet 会先打开翻译窗口，并尝试读取当前前台应用中选中的文本自动预填并提交翻译：

- 读取依赖 macOS「辅助功能」权限。在未授权、焦点不在可读文本框或应用不暴露选区时，翻译窗口仍会正常打开，你可以直接手动输入文本。
- 为兼容各类应用（包括 Chrome / Edge / Safari 等浏览器），Traylet 按分层策略读取选区：优先通过无障碍属性（`AXSelectedText`、`AXStringForRange`、`AXSelectedTextMarkerRange`）及有界遍历读取；若不可用，再依次尝试浏览器 AppleScript/JS 直读、菜单栏 Copy 与模拟 `⌘C`（后两者会备份并恢复剪贴板，且避免污染剪贴板历史）。
- 安全输入框（`AXSecureTextField`）会被拒绝读取；单次选区读取上限为 20,000 字符。

### 截图翻译（默认 `⌃⌥4`）与历史图片 OCR

框选屏幕区域后，Traylet 使用本机 **Vision** 框架识别图片中的文字。识别结果会先填入原文区供你校对和修改，再由你确认提交翻译；在剪贴板历史中也可直接对图片条目发起 OCR 翻译。

## 支持的翻译引擎

### 1. Apple 系统翻译（默认，本机离线）

- 完全在本机运行，不将原文发送至第三方服务器。
- 支持「自动检测」源语言，并对短文本（如单词、短语）内置保守的书写系统回退，减少短文本无法识别的问题；极短或纯数字/符号文本仍可手动指定源语言。
- **系统语言包**：可在「设置 → 翻译 → 系统语言包」选择语种对并检查状态或提前下载。若翻译时缺少对应语言包，窗口内提供直接准备翻译或一键「前往设置下载语言包」（并自动预填当前语种对）。

### 2. 可选外部引擎

可在翻译窗口或设置中切换以下外部服务（由用户主动选择后触发）：

- **AI 翻译（OpenAI 兼容接口）**：支持自定义服务地址、填写 API Key、点击「获取模型」拉取可用列表并通过可搜索下拉面板选择模型，以及「测试连接」。
- **DeepL**：支持配置 API Key 与连接测试。
- **Google** / **MyMemory**：免密钥公共翻译通道。

## 隐私与确认机制

- **密钥存储**：AI 与 DeepL 的 API Key 保存在 macOS 钥匙串（Keychain）中，不写入普通偏好文件；在设置中恢复默认设置时会一并清除。
- **发送前确认**：通过「翻译」按钮首次向某外部引擎发送文本时，界面会展示发送目标与正文并等待确认；同一窗口会话中确认过一次，或你直接点击引擎图标切换时，视为明确提交并直接发送。
- **请求时效性**：修改原文、切换语种/引擎或取消请求时，旧的或迟到的翻译结果会自动作废，不会覆盖当前内容。
