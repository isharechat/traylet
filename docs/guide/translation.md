# 文字与截图翻译

Traylet 支持手动输入翻译、划词预填翻译以及截图 OCR 翻译，默认使用 Apple 本机系统翻译，同时可选接入外部翻译服务。

## 翻译入口

### 输入翻译（默认 `⌃⌥⇧T`）

触发快捷键后，Traylet 会打开翻译窗口并尝试读取当前前台应用中选中的文本自动预填并翻译：

- 读取依赖 macOS「辅助功能」权限；未授权、焦点不在可读控件或无选中文本时，翻译窗口仍会正常打开供手动输入。
- 为兼容各类应用与浏览器，Traylet 按分层策略读取选区：优先通过无障碍属性（`AXSelectedText`、`AXStringForRange`、`AXSelectedTextMarkerRange`）及有界遍历读取；若不可用，再依次尝试浏览器 AppleScript/JS 直读、菜单栏复制与模拟 `⌘C`（后两者会备份并恢复系统剪贴板，且不会污染剪贴板历史）。
- 安全输入框（`AXSecureTextField`）会被拒绝读取；单次选区读取上限为 20,000 字符。

### 截图翻译（默认 `⌃⌥⇧R`）与跨模块跳转

- 框选屏幕区域后，Traylet 先通过本机 **Vision** 框架识别图片中的文字并填入原文区，便于校对修改后再翻译。
- 可从 **截图编辑器**、**OCR 窗口**（`⌘↩`）或 **剪贴板历史图片** 一键发起翻译。

## 支持的翻译引擎

### 1. Apple 系统翻译（默认，本机离线）

- 完全在本机运行，不将原文发送至第三方服务器。
- 支持「自动检测」源语言，并为单词、短语等短文本内置保守的书写系统回退；极短或纯符号文本可手动指定源语言。
- 可在「设置 → 翻译 → 系统语言包」查看与预下载语种对；翻译时若缺少语言包，窗口内可直接触发准备或跳转设置页下载。

### 2. 可选外部引擎

可在翻译窗口或设置中按需切换：

- **AI 翻译（OpenAI 兼容接口）**：支持自定义接口地址、API Key、拉取并搜索模型列表、测试连接以及包含 `{source}` / `{target}` 占位符的自定义提示词。
- **DeepL**：支持配置 API Key 与连接测试。
- **Google** / **MyMemory**：免密钥公共翻译通道。

## 隐私与请求机制

- **凭据安全**：AI 与 DeepL 的 API Key 使用 AES-256-GCM 在本机加密保存（`0600` 权限，独立于普通偏好文件），无需触发 macOS 钥匙串密码弹窗；恢复默认设置时一并清除。
- **发送控制**：默认系统翻译不联网；外部引擎仅在用户显式点击「翻译」或切换引擎时发送当前可见原文。
- **结果时效**：修改原文、切换语种/引擎或取消请求时，旧请求结果会自动失效，不会覆盖当前输入。
