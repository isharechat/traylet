# OCR 文字识别

Traylet 提供独立的 OCR 识别窗口，支持屏幕框选、导入或拖入本地图片，并可在纯本机 Vision 与多模态 AI OCR 之间自由切换。

## 打开方式

- **全局快捷键（默认 `⌃⌥⇧O`）**或菜单栏「OCR 识别」：进入框选模式，选定区域后打开 OCR 窗口。
- **截图编辑器**：点击工具栏中的「OCR」按钮，对当前裁切与标注区域进行识别，同时保留编辑器开启。
- **翻译窗口 / 剪贴板历史**：在翻译窗口点击「截图 OCR / 查看原图」、直接拖入图片，或在剪贴板历史中对图片条目发起识别。

## 窗口与操作

OCR 窗口采用左右分栏设计：

- **左侧原图预览区（可折叠）**：支持缩放（`-` / `+` / 适应）、点击复位、重新截图、导入图片文件或直接拖拽图片。
- **右侧识别文本区**：顶部可切换识别引擎、选择 AI 预设模式、重新识别（`⌘R`）或跳转设置；正文支持直接编辑；底部浮动玻璃胶囊提供朗读、复制（`⌘⇧C`）、智能合并换行、清空及主操作「去翻译」（`⌘↩`）。

## 识别引擎与预设模式

- **本机 Vision（默认，离线）**：基于 macOS 系统 Vision 框架识别，支持在高精度与快速模式间切换，全程不联网。
- **AI OCR（按需外发）**：独立配置 OpenAI 兼容多模态接口（服务地址、API Key、视觉模型名称、拉取模型与连接测试），支持四种预设模式：
  - **纯文本**：忠实提取图片中的文字内容
  - **Markdown 表格**：将表格结构识别为 Markdown 语法
  - **数学公式（LaTeX）**：提取公式并输出 LaTeX 表达式
  - **自定义提示词**：按自定义指令提取结构化内容
- **独立配置**：AI OCR 的接口与密钥独立于翻译模块，API Key 保存在 macOS 钥匙串中。切换引擎时会自动清空旧结果并重新识别。

## 文本后处理

- **智能合并换行**：保留段落空行（`\n\n`），自动拼接被折行的段落——中文字符相邻直接连接，西文之间自动补空格。
- **自动复制**：可在「设置 → OCR」中开启识别完成后静默自动复制到剪贴板。
